HoopUp

Started May 2026 · Last updated Jul 2026 · Public · Live site · Source

  • Pickup-basketball app: find nearby courts on a live map, host a game, and RSVP.
  • Court data comes from OpenStreetMap through the Overpass API and is cached on the server.
  • A Postgres trigger enforces the 15-player cap and waitlist atomically, so games can't overbook.
  • Player profiles, friends, favorite courts, and a live "Hooping" status once a game starts.
  • Email/password, Google, and GitHub sign-in, with row-level security on all data.

The Kitchen Club

Started Jul 2026 · Last updated Sep 2026 · Private · In development

  • New web product, currently in its foundation phase.
  • Turborepo monorepo with a Next.js app plus shared packages for the UI, domain model, API client, database, and auth.
  • Zod schemas act as the single validation layer and the source of the app's types.
  • Postgres on Neon with Drizzle ORM migrations; Better Auth keeps sessions in its own database.
  • CI runs formatting, linting, type checks, tests, and builds, and database migrations are gated.
